# Olist finishing kit — historical planning material

The active, executable project is [`dbt-snowflake-ecommerce`](https://github.com/Raveesh-rajg/dbt-snowflake-ecommerce). Start there for fixture loading, 17 models, a snapshot, 73 dbt tests, nine Python regression checks and export commands.

This repository preserves the original planning notes, Tableau specification and measurement templates. It is not a second completed warehouse. Placeholder runtime, cost, dashboard and résumé figures in these drafts are not measured results and should not be quoted as achievements.

Live Snowflake execution and a published Tableau dashboard remain separate validation gates. No current cloud-cost evidence is recorded here.
